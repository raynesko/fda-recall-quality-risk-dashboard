# T6.2.1 - DMAIC QA action library per failure mode

**Sub-epic:** SE6 Dashboard & DMAIC Recommendations  |  **Story S6.2:** As a QA lead, I want each flagged failure mode translated into DMAIC-framed QA actions, so that insights lead to something I can act on.

## Description
For >= 8 categories (all vital-few and any flagged) write Define/Measure/Analyze/Improve/Control actions a QA function could take: owner function, example metric, and a cited requirement or guidance. Candidate citations to VERIFY on eCFR before use (do not trust this list): 21 CFR 211.113 (microbiological contamination control), 211.165 (testing/release), 211.166 (stability), 211.192 (production record review), 21 CFR 117.130/117.135/117.150/117.165 (hazard analysis, preventive controls, corrective actions, verification), ICH Q9/Q10. State prominently that actions are generic hypotheses from category-level patterns, never findings about a named firm.

- [x] Disclaimer text appears at the top of the markdown and on the dashboard page
