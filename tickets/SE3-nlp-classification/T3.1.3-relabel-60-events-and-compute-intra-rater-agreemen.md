# T3.1.3 - Relabel 60 events and compute intra-rater agreement

**Sub-epic:** SE3 Root-Cause Classification (NLP)  |  **Story S3.1:** As an analyst, I want a hand-labeled, agreement-checked gold set, so that classifier accuracy is measurable rather than asserted.

## Description
[Amended 2026-11-16: labels are LLM-produced] An independent second LLM annotator (separate session, given only taxonomy + guide, blind to annotator A) labels a random 60 events. Compute Cohen's kappa. If kappa < 0.75, revise the guide, resolve disagreements, record before/after kappa, then freeze labels.

## Acceptance criteria
- [x] Relabel file contains 60 event_ids chosen with a documented seed and generated without exposing prior labels
- [x] Cohen's kappa computed with sklearn.metrics.cohen_kappa_score and reported with the disagreement list
- [x] Target kappa >= 0.75; if missed, guide v2 and post-revision kappa are documented
- [x] Final gold labels frozen: sha256 recorded via record_metric
- [x] Report states clearly that this is agreement between two LLM annotators (not human), with its limitations
