# T3.2.2 - ML classifier: TF-IDF + logistic regression with grouped CV

**Sub-epic:** SE3 Root-Cause Classification (NLP)  |  **Story S3.2:** As an analyst, I want an NLP classifier that demonstrably beats a keyword baseline, so that every recall is assigned a root-cause category at scale with known accuracy.

## Description
TF-IDF word 1-2-grams (optionally char n-grams) + LogisticRegression(class_weight='balanced'). Cross-validate with GroupKFold(5) grouped by normalized recalling_firm to avoid leakage from near-identical texts. Compare to the keyword baseline on the SAME out-of-fold rows.

## Acceptance criteria
- [x] Out-of-fold macro-F1 reported with a 95% bootstrap CI (>= 1000 resamples, seeded)
- [x] Paired comparison vs keyword baseline: difference in macro-F1 with 95% bootstrap CI and McNemar p-value on accuracy
- [x] TARGET (not an achieved result): macro-F1 >= 0.80 and >= +0.10 over baseline. Report the actual numbers either way via record_metric
- [x] Confusion-matrix PNG saved; per-class P/R/F1 table appended to classifier_eval.md
- [x] Fixed seed; `pytest tests/test_model.py` verifies deterministic predictions on a fixture
