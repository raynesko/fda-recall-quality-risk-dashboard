# T2.3.1 - Spike (stretch): adverse-event (FAERS) linkage feasibility

**Sub-epic:** SE2 Data Acquisition & Modeling  |  **Story S2.3:** (Stretch) As a regulatory data analyst, I want adverse-event context next to recall findings, so that I can see whether recalled drugs also show reporting activity - without implying causation.

## Description
TIME BOX 1.5h. Test whether drug/event data can be joined to drug recalls by generic/brand name in a defensible way. Output is a go/no-go.

## Acceptance criteria
- [ ] Queries for 3 sample drugs from the recall data are run against drug/event and results recorded
- [ ] Name-matching coverage on the top 20 recalled drug names is measured (x of 20 matched)
- [ ] FAERS limitations listed (spontaneous reporting, duplicates, no causality, no exposure denominator)
- [ ] Go/no-go decision written with reason
