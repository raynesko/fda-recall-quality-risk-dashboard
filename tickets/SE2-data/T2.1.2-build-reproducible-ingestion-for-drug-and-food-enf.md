# T2.1.2 - Build reproducible ingestion for drug and food enforcement data

**Sub-epic:** SE2 Data Acquisition & Modeling  |  **Story S2.1:** As an analyst, I want a reproducible ingestion and cleaning pipeline from openFDA, so that anyone can rebuild the dataset from source and trust the counts.

## Description
Implement ingestion per the T2.1.1 decision. Raw files are immutable and stored under data/raw/<endpoint>/<retrieval_date>/. Optional API key is read from env var OPENFDA_API_KEY and never committed.

## Acceptance criteria
- [x] `python -m fda_recall.ingest --endpoint drug food` completes and writes raw files plus manifest.json
- [x] manifest.json records per file: source URL, retrieval timestamp (UTC), row count, sha256
- [x] Re-running is idempotent: second run skips existing files unless `--force` is passed (verified by test)
- [x] Row count in manifest equals the API meta total or documented bulk-file record count
- [x] `pytest tests/test_ingest.py` passes using mocked HTTP (no network in tests)
- [x] `git grep -i api_key` finds no committed secret; data/raw/ files are gitignored but manifest.json is tracked
