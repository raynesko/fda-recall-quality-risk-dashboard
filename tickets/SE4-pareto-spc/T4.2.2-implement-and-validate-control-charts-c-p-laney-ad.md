# T4.2.2 - Implement and validate control charts (c, p, Laney-adjusted) with run rules

**Sub-epic:** SE4 Pareto, Trend & Control-Chart Analysis  |  **Story S4.2:** As a QA manager, I want control charts and trend tests on recall activity by category, so that I can separate real shifts (special-cause) from noise (common-cause).

## Description
No production denominator exists, so use (a) c-chart on monthly event counts and (b) p-chart on category share of that month's events (handles overall volume swings), each with a Laney-style overdispersion adjustment when dispersion > 1. Phase I baseline window configurable (default 2015-01..2019-12): remove special-cause points iteratively, document each. Phase II monitors later months. Rules: point beyond 3 sigma; 8 consecutive points on one side of the centre line. LCL floored at 0.

## Acceptance criteria
- [x] Formulas verified against hand-calculated values on a toy dataset (tolerance 1e-9) in tests
- [x] Output has per category-month: cl, ucl, lcl, signal flag and rule id
- [x] Simulation: 1,000 stable Poisson series (n=60) give an empirical false-alarm rate for rule 1 and run rule, reported via record_metric
- [x] Charts for top 6 categories saved; signals marked and labeled with rule
- [x] Sensitivity: signal counts for 3 alternative baseline windows reported side by side
- [x] Docs state clearly that chart limits describe process stability of FDA-recorded recall activity, not firm quality
