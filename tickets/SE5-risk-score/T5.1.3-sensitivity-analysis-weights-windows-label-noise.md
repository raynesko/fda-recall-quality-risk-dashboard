# T5.1.3 - Sensitivity analysis: weights, windows, label noise

**Sub-epic:** SE5 Risk Scoring & Backtest Validation  |  **Story S5.1:** As a QA lead, I want a transparent risk score that flags rising failure modes and has been backtested against naive baselines, so that I can trust (or challenge) its flags.

## Description
(a) 1,000 Dirichlet(1,...,1) weight draws -> distribution of each category's rank; (b) trailing-window length 6/12/24 months; (c) inject random label noise at the classifier's measured error rate and re-rank. Output a per-category 'flag stability' (% of runs in which it stays flagged).

## Acceptance criteria
- [x] Median Kendall tau vs default ranking reported (TARGET >= 0.70)
- [x] Per-category flag-stability table written to reports/tables/flag_stability.csv
- [x] Rank-stability chart saved
- [x] Fragile flags (<60% stability) are named in the report
